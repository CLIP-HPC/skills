`plugin-1.0.0.schema.json` is an unmodified snapshot of the
[Agent Plugins 1.0.0 manifest schema](https://agent-plugins.org/schemas/1.0.0/plugin.schema.json),
retrieved on 2026-10-19. It allows validation without network access.

When deliberately upgrading the portable manifest version, fetch the matching
published schema, review its changes, and update `SCHEMA` in `scripts/bundle.py`.
